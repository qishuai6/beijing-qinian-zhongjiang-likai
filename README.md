# 北京七年，终将离开

> 384 分初试第一却落榜的冬天、80 块钱的被褥、12 平米的房子、漏雨的窗户、那张忍不住发朋友圈的工卡、胡同里养了十年的发财树，还有 2022 年年底收拾行李时的那种感觉。

这是一本自传，写的是我在北京待了七八年的完整经历：从考研落榜的冬天，到第一次进大厂、在理想汽车做交互设计，再到买完房卡里只剩 200 块、领证结婚、最后离开北京回郑州。它最早的名字叫《工作十年》。

我想记录的不是"我在北京工作了多少年"，而是那些年我是怎么一步一步走过来的——遇到事情的时候怎么想，碰到岔路口的时候怎么做决定，那些看起来普通、其实会影响一个人很多年的时刻，到底是怎么发生的。

全书约 9.8 万字，24 章，另有序言。

## 关于写作方式

这本书的成书过程本身就有点特别：2022 年底动笔，用"一整块时间写书"的方式写了三章就停了。后来我把工作以来写过的 600 多篇文章导出来，让 AI 分析我的表达习惯，做了一个"数字分身"，再由我口述、它整理成稿。详细的故事写在[自序](./北京七年，终将离开.md)里。
